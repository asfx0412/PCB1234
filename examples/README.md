# UniPCB Examples

This folder contains a small format-preview subset for quick inspection and
smoke testing.

```text
examples/
  sample.json
  summary.json
  images/
```

The example subset is not a replacement for the full dataset release. It is
included only to show the annotation schema, image path format, task structure,
and expected file layout.

The full image payload should be obtained from the dataset release URL and
unpacked under `data/benchmark/raw/`.
